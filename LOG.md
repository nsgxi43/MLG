### Stage 4 representation check failed — corrected before final reporting
The sparse cycle block omitted keys that were zero for all training graphs. The authors' feature vectors retain a cycle column for each node-label column. Although adding zero coordinates leaves linear-kernel values unchanged, it changes the RF feature-sampling pool. Thus the prior cycle-method measurements are preliminary compact-vocabulary variants, not final source-faithful comparisons. Stopped the in-progress run and retained its completed checkpoints and outputs under results/compact-cycle-columns/. WL/P-WL values are unaffected, and final comparisons use the completed corrected run. Corrected pwl.py to initialize zero cycle keys for every current node label, bumped the persistence cache version, and validated exact 2× column counts and repeated all cycle/extension checks before the corrected full run. This was an implementation mismatch, not an adjustment to favor a method.
